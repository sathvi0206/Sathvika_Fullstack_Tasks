# Task 1 - Student Profile Using Props

## Objective

Create a reusable Student component and pass student details using React props.

## Props Used

- Name
- Roll Number
- Course
- College

## Files

- `App.jsx` - Main component and passes student details as props.
- `Student.jsx` - Displays the student profile.
- `App.css` - Provides styling for the student profile card.

## Expected Output

A Student Profile card displaying:

- Name: Sathvika
- Roll No: 101
- Course: CSE
- College: Prathyusha Engineering College

## Concepts Used

- React Components
- Props
- JSX
- CSS
