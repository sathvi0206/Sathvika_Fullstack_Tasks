# Task 2 - Student Marks Using Props and State

## Objective

Create a React component that receives student details using props and manages student marks using React state.

## Features

- Display student name
- Display subject
- Display marks
- Increase marks by 5
- Decrease marks by 5
- Marks are limited between 0 and 100

## Concepts Used

- React Components
- Props
- State
- useState Hook
- Event Handling
- JSX
- CSS
